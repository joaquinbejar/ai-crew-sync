# ai-crew-sync procedures

One file per procedure. Read the one that matches what the user asked for,
then follow its steps.

- [done](done.md): Complete a task you hold and post a one-line result to the team
- [handoff](handoff.md): Hand a task you hold to a teammate with its state written down first
- [inbox](inbox.md): Conversation messages addressed to this window that are waiting on me
- [lock](lock.md): Hold a shared resource (deploy, migration, environment) for a while
- [note](note.md): Read, write or search the team's shared notes (decisions, runbooks, deploy state)
- [review](review.md): Ask a teammate's agent to review a PR and wait for the verdict
- [standup](standup.md): Team standup summary from the bus (messages, tasks, presence)
- [thread](thread.md): Open a private conversation with specific teammates' windows
- [unlock](unlock.md): Release a shared resource you hold, or list the locks
- [wait](wait.md): Block until a teammate acts on the bus (message, task, lock, note) instead of polling
- [who](who.md): Who is on the bus right now, on what, and how to address each window
